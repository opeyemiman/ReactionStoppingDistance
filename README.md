# MATLAB Scripts
Scripts focus on illustrating stopping and braking distances using coefficient of friction, starting speed and pedestrian exposure time. Available braking distance is determined from the pedestrian exposure time; braking distance is calculated from speed and friction

## total_braking_distance.m 
Calculates braking distance - the distance after the perception-reaction phase and compares that to available braking distance based on exposure time 

## total_stopping_distance.m
Calculates braking distance, and adds perception-reaction distance to determine total stopping distance; compares that to available total stopping distance based on exposure time and PRT
